# Interactive Image Distort Effect

A WebGL-powered interactive effect that distorts an image using particles. Move your mouse over the canvas to create dynamic distortions and watch the logo smoothly return to its original shape.

## Features
- Renders an image as thousands of particles using WebGL shaders
- Real-time interactive distortion based on mouse movement
- Smooth particle physics for natural return animation
- Customizable logo, colors, and distortion parameters

## Usage
1. Open index.html in your browser.
2. Move your mouse over the canvas to interact with the effect.
3. Customize settings in script.js (logo path, colors, distortion strength, etc).

## Tech Stack
- HTML5 Canvas
- WebGL (custom vertex & fragment shaders)
- JavaScript (ES6 modules)

## Files
- index.html — Main HTML file
- script.js — Core logic and rendering
- shaders.js — GLSL shader code
- logo.png — Image used for the effect
